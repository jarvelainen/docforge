# Fujitsu Brand Assets

This directory contains the Fujitsu reference materials included in the distributable DocForge engine package.

The initial package includes the supplied reference library so builds can access approved fonts, logos, symbols, icons, PowerPoint reference graphics, and Infinity assets without depending on another repository.

The source was copied from `C:\GitHub\Documentation\FujitsuReferenceMaterial` during initial DocForge setup. It contains 276 files and is approximately 105 MB.

Release curation may later separate frequently required runtime assets from optional reference material. Do not remove or replace assets without checking licensing, visual requirements, and build compatibility.

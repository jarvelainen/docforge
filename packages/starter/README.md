The starter is the canonical empty report project. It uses lorem ipsum and representative structures to validate the DocForge build, three-level navigation, H3 tabs, content components, responsive behavior, print, and offline output.

Validated baseline:

- 58 px navigation row plus 49 px toolbar at normal widths.
- Header height is measured and content begins below the complete header.
- Navigation wraps into balanced rows instead of horizontal scrolling.
- Heading 1 pages are direct navigation items and grouped Heading 2 pages use an accessible dropdown.
- Page-specific H3 tabs use keyboard-accessible tab semantics.
- The engine supports report, sales, and offer as peer channels; only report is implemented for the starter baseline.
